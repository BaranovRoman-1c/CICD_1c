# 1C FullStack

Проект воспроизводимого CI/CD-окружения для конфигураций и расширений
1С:Предприятия. Репозиторий: `BaranovRoman-1c/CICD_1c`.

Планируемые компоненты: Docker Compose, PostgreSQL, платформа 1С,
Jenkins и GitHub. Сейчас подготовлены структура и документация;
исполняемые конфигурации инфраструктуры и pipeline ещё не добавлены.

## Структура

| Путь | Назначение |
| --- | --- |
| `AGENTS.md` | Правила работы AI-агента и требования к проверкам |
| `docs/` | Окружение и предварительная архитектура |
| `infrastructure/compose/` | Будущие Compose-конфигурации |
| `infrastructure/docker/` | Будущие Dockerfile и контексты сборки |
| `ci/` | Будущие Jenkins pipeline и общие CI-сценарии |
| `scripts/checks/` | Будущие безопасные скрипты проверок |
| `tests/infrastructure/` | Будущие проверки инфраструктуры |

## Документация и работа с проектом

- [Окружение разработки](docs/environment.md)
- [Предварительная архитектура](docs/architecture.md)
- [Правила AI-агента](AGENTS.md)

Работайте в отдельных ветках. Commit и push требуют явного подтверждения.
Секреты, токены, лицензии, установочные пакеты 1С и данные баз не должны
попадать в репозиторий. В шаблонах `.env.example` допустимы только заглушки.
`.gitignore` не заменяет проверку содержимого перед добавлением файлов в Git.

## Проверки

Локальная статическая проверка пробельных ошибок: `git diff --check`.
Для новых неотслеживаемых файлов нужна отдельная проверка содержимого:
обычный `git diff` их не включает.
Runtime- и интеграционные проверки будут определены вместе с инфраструктурой.
Наличие документации не подтверждает работоспособность сервисов.
