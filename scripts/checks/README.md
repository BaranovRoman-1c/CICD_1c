# Скрипты проверок

Каталог для будущих повторяемых проверок проекта.
Скрипты должны возвращать ненулевой код при ошибке, описывать зависимости
и явно отделять статические проверки от runtime и интеграционных.
Проверки не должны удалять данные или запускать сервисы без согласования.
Исполняемых скриптов пока нет.
