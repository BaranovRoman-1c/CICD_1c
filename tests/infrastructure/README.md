# Проверки инфраструктуры

Каталог для будущих проверок Compose-конфигураций, healthcheck сервисов
и взаимодействия 1С с PostgreSQL. Для каждого теста необходимо описать
предусловия, тип проверки и ожидаемый результат.
Runtime- и интеграционные тесты используют только изолированное test-окружение.
Тесты пока не реализованы.
