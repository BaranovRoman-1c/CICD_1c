# Docker Compose

Каталог для будущих Compose-конфигураций PostgreSQL, Jenkins и сервисов 1С.
Конфигураций пока нет. При реализации фиксируйте версии образов, разделяйте
development и test, передавайте секреты извне и документируйте volumes.
Запуск или остановка существующих сервисов требует согласования.
Удаление volumes и баз данных запрещено.
